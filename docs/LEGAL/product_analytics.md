# Согласие на продуктовую аналитику

Версия: 2026-08-24

Разрешает собирать технические события продукта (`mwe_*`): открытие приложения, просмотр события, отправка заявки. В свойствах — только идентификаторы, без телефона, email и документов.

Без согласия сохраняются только служебные health-метрики без user id.

Согласие можно отозвать в профиле. Транспорт аналитики на Stage 1 ещё не подключён; запись согласия уже обязательна, чтобы не включать сбор задним числом.
