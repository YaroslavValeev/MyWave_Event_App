# Пользовательское соглашение

Версия: 2026-08-24  
Продукт: MyWave Event App

Это рабочая редакция Stage 1, не заменяющая юридическую экспертизу.

## 1. Предмет

MyWave Event App — самостоятельная цифровая платформа соревнований: события, роли, заявки, документы, расписание тренировок.

## 2. Аккаунт

Вы регистрируетесь по телефону и email. Роль «Участник» активируется сразу. Иные роли требуют утверждения организатором.

## 3. Правила

Запрещено выдавать чужие данные, обходить контроль доступа и публиковать заведомо ложные сведения о событии.

## 4. Контент события

Организатор отвечает за положения, стартовые списки и допуск. Приложение хранит и показывает данные в пределах роли пользователя.

## 5. Изменения

Новая версия соглашения потребует повторного согласия. Продолжение работы без согласия с обязательными документами невозможно.
