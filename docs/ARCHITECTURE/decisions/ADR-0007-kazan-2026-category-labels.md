# ADR-0007 — Категории Казани-2026: не выбирать молча между «до 15/до 19» и U14/U18

**Дата:** 2026-08-30  
**Статус:** proposed (нужно решение владельца / главного судьи до публикации start lists)

## Контекст

В материалах ЧР/ПР 2026 Казань расходятся формулировки возрастных категорий:

- бюллетень использует «до 15» и «до 19»;
- правила IWWF 2026 и рабочая таблица по категориям используют U14 / U18 (и Open).

Молча выбрать один вариант нельзя: это меняет допуск и стартовые списки.

## Решение (пока)

1. Категория события — **event-specific configuration**. Оригинальная подпись из каждого источника сохраняется в строке импорта (`category_label` / `raw_json`).
2. Возраст для проверки считается на **31 декабря года соревнования**.
3. Канонические коды категорий **не публикуются в start lists**, пока владелец или главный судья не подтвердит таблицу соответствия.
4. Импорт не переписывает спортивные правила. Расхождение фиксируется как `decision required`, не как bugfix скоринга.

## Предлагаемая таблица соответствия (черновик, не канон)

| Бюллетень | IWWF / рабочая таблица | Примечание |
|-----------|------------------------|------------|
| до 15 | U14 | **не эквивалентны без решения КС** |
| до 19 | U18 | **не эквивалентны без решения КС** |
| Open / абсолют | Open | обычно совпадает |

## Последствия

- Import Center показывает исходный `category_label`.
- До решения КС start lists Казани-2026 не считать официальными.
- После решения этот ADR переводится в `accepted` с выбранной канонической колонкой.

## Отвергнуто

- Автоматически мапить «до 15» → U14 в коде.
- Хранить две параллельные SoT-таблицы категорий на одно событие.
