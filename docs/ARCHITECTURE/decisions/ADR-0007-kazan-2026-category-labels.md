# ADR-0007 — Категории Казани-2026: канон IWWF

**Дата:** 2026-08-30, принято 2026-08-31  
**Статус:** accepted

## Контекст

В материалах ЧР/ПР 2026 Казань расходились формулировки:

- бюллетень: «до 15» / «до 19»;
- рабочий Excel: «Девочки U14», «Юноши U18», «Женщины» / «Мужчины» (мастера 30+ внутри взрослых);
- IWWF start list: U14, Junior, Grom, U18, Open.

ЧР и ПР проходят совместно — **одно событие**, не две карточки.

## Решение владельца (2026-08-31)

1. Одно событие: «Чемпионат России в Казани 2026» (ЧР + ПР вместе).
2. Канон категорий для состава, стартов и протокола — **IWWF**:
   - **U14**, **U18** — первенство;
   - **Open** — чемпионат;
   - **O30**, **O40** — мастера.
3. Возраст считается на **31 декабря года соревнования** (2026).
4. Исходная подпись источника сохраняется в `Category.notes` / строке импорта (`source_label`).

## Таблица соответствия

| Источник | Канон |
|----------|--------|
| до 15, Девочки/Мальчики U14, Under 14, Grom | U14 |
| до 19, Девушки/Юноши U18, Under 18, Junior / Jun | U18 |
| Женщины / Мужчины / Open, возраст младше 30 | Open (чемпионат) |
| те же взрослые, возраст 30–39 | O30 |
| те же взрослые, возраст ≥ 40 | O40 |

Пол кодируется в `Category.code` (`wb-u14-f`, `ws-open-m`, …) и в заголовке («· жен.» / «· муж.»).

## Последствия

- Import Center и ingest-pack создают категории только с IWWF-кодами.
- Junior и Grom в PDF **не** отдельные классы.
- Бюллетень «до 15/до 19» больше не конкурирует как SoT.
- Сканы протоколов заездов раскладываются в те же коды, когда владелец их пришлёт.

## Отвергнуто

- Две карточки событий ЧР и ПР.
- Две параллельные SoT-таблицы категорий на одно событие.
- Оставить Excel «Женщины/Мужчины» как канон протокола.
