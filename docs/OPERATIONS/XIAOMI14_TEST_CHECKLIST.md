# Чек-лист проверки Champ App на Xiaomi 14 (Mi 14)

Дата: 2026-11-03  
Версия продукта для проверки: **0.5.18+**  
Канал установки сейчас: **Web / PWA** (нативный APK **не собран** — нет JDK/SDK на build-машине; см. `ANDROID_BUILD.md`).

## Перед тестом

1. Убедиться, что доступен staging или локальный HTTPS/HTTP URL web + API.
2. Получить тестовый телефон/email для OTP (или `dev-login` только на development).
3. Записать версию HyperOS / Android с телефона.
4. **Не** устанавливать APK из непроверенных источников. Пока APK нет — используйте Chrome.

## Установка (Фаза A — PWA / браузер)

1. Открыть URL приложения в Chrome на Xiaomi 14.
2. Меню ⋮ → «Установить приложение» / «Добавить на главный экран» (формулировка HyperOS может отличаться).
3. Открыть ярлык Champ App.
4. Разрешить камеру и доступ к фото **только когда система спросит** при создании публикации.

## Диагностика при FAIL

Передать владельцу **без** паролей/OTP/токенов:

- ID шага, время, Wi‑Fi/мобильная сеть
- версия Android/HyperOS, версия приложения (`/health` или о сайте)
- скриншот + шаги воспроизведения
- текст ошибки с экрана

## Фаза B — APK (пока BLOCKED)

Когда появится debug APK:

1. Скачать из утверждённого Release / канала владельца.
2. Сверить SHA-256.
3. Установить с разрешением только для этого источника.
4. Повторить X14-01…X14-12.
5. После установки отключить «неизвестные источники» для файлового менеджера.
