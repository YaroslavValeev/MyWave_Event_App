MyWave Event App — установка и запуск

Цифровая платформа соревнований: заявка, старт, судейство и протокол. Текущая готовая оболочка — веб-приложение (PWA) в браузере телефона и компьютера. Нативные сборки Android и iOS подключаются отдельно, когда появятся файлы.

1. Открыть готовое приложение

  1. Локально: http://127.0.0.1:3000
  2. Staging: порт web 3001 на сервере Event App
  3. Карточка выдачи: /projects/checklist-org#mywave-event-app

2. Запуск из исходников

Нужны Python 3.11+, Node.js 20+, Git. Секреты не хранятся в Git — скопируйте .env.example в .env.

npm run dev

API: http://127.0.0.1:8000 · Web: http://127.0.0.1:3000 · проверка: GET /health

Только интерфейс, если API уже запущен:

npm run dev:web

3. Первый вход

  • Участник: /register — сразу активен
  • Организатор, судья и другие staff-роли: регистрация → ожидание подтверждения
  • Вход: /login по телефону, код приходит на email (или в data/mail_outbox, если SMTP не настроен)

4. Чек-лист организатора

Подготовка конкретного соревнования — вкладка «Подготовка» карточки события. Готовое решение приложения — раздел «Проекты → Чек-лист организатора».

5. Нативные файлы

APK, TestFlight и архив исходников появляются в карточке только после подключения реальных HTTPS-ссылок в окружении API. Пока ссылок нет, интерфейс показывает «файл временно недоступен» и не подставляет выдуманные адреса.
