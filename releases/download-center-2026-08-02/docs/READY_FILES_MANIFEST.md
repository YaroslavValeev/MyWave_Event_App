# Манифест готовых и ожидаемых файлов MyWave Event app

Дата упаковки: 2026-08-02

## Входит в готовый релизный комплект

- серверный Download Center для существующего Flask-сайта;
- адаптивный и доступный UI;
- безопасная конфигурация четырёх каналов выдачи;
- API manifest/status/handoff;
- клиентская аналитика и обработка состояний;
- автоматические тесты;
- PRD, Technical Design, Runbook и Implementation Report;
- patch относительно актуального `origin/main`;
- контрольные суммы файлов комплекта;
- локальные скриншоты desktop/mobile после тестового запуска.

## Не входит: исходные данные не предоставлены

| Ожидаемый файл | Статус | Что требуется |
|---|---|---|
| Android APK/AAB | Не предоставлен | Подписанная сборка, версия, SHA-256, min Android, размер |
| iOS/TestFlight | Не предоставлен | Реальный invite URL, версия/build, min iOS, доступ группы |
| ZIP мобильных исходников | Не предоставлен | Очищенный архив и README сборки |
| Документация приложения | Не предоставлена | Инструкция пользователя и инструкция разработчика |

Комплект намеренно не содержит фиктивных бинарников, пустых APK/IPA или тестовых внешних ссылок.
